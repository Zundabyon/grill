13 MP3 recordings selected from samples/bass-electric. Stored files are unmodified.
During playback, Grill trims leading silence, shifts playback rate by at most
two semitones across the supported E1–Eb4 range, and applies gain, EQ,
compression, and a short note-off fade. No upstream loader code is used.

This sample license is separate from the application code and chart data.
