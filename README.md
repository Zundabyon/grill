# Grill

お手本から、あなたのラインへ。

PCブラウザで使う、4弦ベース（E A D G）のウォーキングベース練習アプリ。
コード進行から運指つきTABを生成し、音を選んだ理由を確認しながら、
自分で音を変更して聴き比べられます。バックエンド・アカウント・APIキーは不要です。

## 起動

Node.js 22以上を使用します。外部npm依存はありません。

**Macでは `Grillを起動.command` をダブルクリック**すると、サーバーを起動して
ブラウザでGrillを開きます。表示されたターミナルは練習中そのまま開いておいてください。
終了はControl + Cです。HTMLファイルの直接オープンではアプリは動作しません。

```sh
npm run dev
```

http://127.0.0.1:5173 をブラウザで開きます。ポート変更は `PORT=5174 npm run dev`。

```sh
npm test
npm run build
```

`dist/` は静的ホスティング用の出力です。リソースは相対パスで参照します。
直接HTMLファイルを開く方法（file://）には対応していません。

## できること

- ワイマールの曲名・演奏者検索、手入力、MusicXML / JSON / TXT取り込み
- 「スタンダード33曲」を初期表示。同じ曲の演奏違いは代表1資料に絞り、「全資料」で元の一覧へ切り替え可能
- 入力キーから練習キーへの移調
- 初期値は「1曲まるごと」。曲を選ぶと1小節目から曲末まで生成。4・8・16小節の区間練習と開始小節指定にも切り替え可能
- 簡単・普通・難しめと、独立したフレット範囲・BPM設定
- 4/4拍子、1拍1音のウォーキングライン生成とTAB表示
- ベース音とクリック、カウントイン、区間ループ、リアルタイムのテンポ変更
- 音ごとの役割・次の音とのつながりの説明
- 指板での音の編集、お手本への復元
- ブラウザ内保存（最大50件）、保存データのJSON書き出し・再取り込み
- Spaceキーで再生・停止（入力欄にフォーカスがある間は無効）

## 練習の流れ

1. 曲を選ぶか、`Dm7 | G7 | Cmaj7 | A7` のように進行を入力。
2. キー・範囲・難易度を選び「ラインをつくる」。
3. TABの音を選び、指板と説明を確認。
4. 「自分で変える」で指板をクリックし、自分の音を試す。
5. ベースをオフにしてクリックだけで弾く、または音ありで聴き比べる。

初版のお手本は、コード変更時のルート／指定ベース音、構成音、隣接アプローチを
使う学習用モデルです。ジャズの全スタイルの規則や唯一の正解を表すものではありません。
同じラインを反復し、別案はボタンで生成します。
移動量・弦移動・同音反復などを評価する探索で運指を選びますが、
実際の手の大きさ・指使い・音楽的な好みは保証できません。
難易度の運指基準は実奏しながら調整する初期値です。

## データとライセンス

すぐ選べる33曲の一覧と収録演奏者は [STANDARDS.md](STANDARDS.md) に記載しています。
33曲すべてについて、曲全体を3段階の難易度で生成できることをテストしています。
選曲と代表資料の対応は `src/catalog.js` で管理します。

`data/weimar.json` はWeimar Jazz Databaseから抽出したコード進行の派生データベースです。
ODbL 1.0 / DbCL 1.0の通知、配布版、SHA-256を保持し、アプリからもダウンロードできます。
原資料の演奏者とIDを表示します。詳細は [data/NOTICE.md](data/NOTICE.md)。
アプリ本体のコードと曲データのライセンスは別です。現段階でアプリ本体に
オープンソースライセンスは設定していません。

公式配布版456資料を収録し、`supported`で初版対応可否を区別しています。
未対応資料は曲選択で明示します。コード記号は一部を内部で正規化しますが、
配布データ内の原文は保持します。

**Fly Me To The Moon / Autumn Leaves / Blue Bossa** はJazz Harmony Treebankから追加しています。
この3曲のデータは **CC BY-NC-SA 4.0（非商用）** で、ワイマールのODbLデータと
別ファイルに保持しています。個人練習用として使い、商用化するときはこのデータの
利用条件を改めて扱う必要があります。出典・原版・変更内容は [data/JHT-NOTICE.md](data/JHT-NOTICE.md)。
各曲の元の小節・拍配置を保持し、検索別名を追加しています。
保存・書き出しにも出典とライセンス情報を保持します。手元の別バージョンも
iReal Proから非圧縮MusicXMLを書き出して取り込めます。
初期画面の進行は自作の練習用例で、Autumn Leavesのデータではありません。

## 対応範囲と制限

- 4/4拍子、1小節1・2・4コード。3コードや拍の途中での変更はエラーにします。
- テンションは表記を保持し、基本構成音を中心に生成。全テンションを生成候補には含めません。
  `pcs` / `intervals` は生成・指板の強調・解説で共用する採用音の集合です。
  C9の完全な構成音はC/E/G/Bb/D、Cmaj9はC/E/G/B/Dですが、
  この生成モデルではそれぞれC/E/G/Bb、C/E/G/Bに絞り、9度は省略します。
  Cadd9はC/E/G/Dを採用し、7度を追加しません。
  半減七のø・ø7・h・h7・m7b5は同じ構成音として扱います。
  構成音の表示はコードのルートと度数に合わせ、Cdim7のBbbは減7度として説明します。
- MusicXMLはコード記号を持つ最初のパートを使用。繰り返し・コーダ・不完全小節・
  複雑な声部構造は、黙って展開せずエラーにします。
- iReal独自HTML、irealbリンク、圧縮MXL、PDF、MIDI、音声認識は未対応です。
- ワイマールには4/4以外や独自表記を含む資料もあり、すべての資料を生成できるわけではありません。
- エレキベースの録音サンプル13音を同梱（約4MB）。近い音高のサンプルを再生し、アタックを残してEQ・軽いコンプレッション・音の終わりのフェードを適用します。初回再生時に読み込み・デコードし、以後はメモリ上の音源を再利用します。読み込みに失敗した場合はエラーを表示します。クリック音は合成音です。
- 音源はKaroryfer / N. P. Brosowskyのtonejs-instruments由来、CC BY 3.0。出典と加工内容は [音源の通知](assets/bass-electric/NOTICE.md) を参照してください。
- 練習保存はこのブラウザのローカルストレージ。同期はありません。
  ブラウザデータを消すと失われるので、必要な練習はJSONを書き出してください。
- Google Fontsへの接続がなくても、システムフォントで動作します。
- ブラウザがバックグラウンドになると、タイミングの崩れを避けるため再生を停止します。
- 初版はPC優先。スマホ専用アプリ・PWA・自動採点は後続の範囲です。

## 構成

- `src/music.js`: コード解析・移調・運指探索・説明。DOMに依存しない。
- `src/audio.js`: 音声時計に基づく先行スケジューリングと再生停止。
- `src/import.js`: MusicXMLの検証とコード進行抽出。
- `src/app.js`: 画面とローカル保存。
- `scripts/extract_weimar.py`, `scripts/validate-data.mjs`: データ抽出の再現。
- `tests/`: 音楽ロジック・データ対応の回帰テスト。

後からスマホ用UIや別の音源を追加できるよう、生成処理と画面を分離しています。

## ピアノ・ドラム伴奏

再生バーの下でピアノ・ドラムを個別にオン／オフでき、ベースを含む3楽器の音量を調整できます。
ベースをオフにすると、ピアノとドラムをバックに練習できます。クリックも独立して使用可能です。
音量・オン／オフは再生中にも反映します。設定は練習保存に含まれず、再読み込みで初期値に戻ります。

ピアノ・ドラムはWeb Audioによる端末内合成で、追加の録音音源やダウンロードはありません。
ピアノは柔らかい電子ピアノ風の倍音合成です。原則ルートを省いた構成音をC4〜B4に配置し、
コード変更拍と1・3拍目に鳴らします。全テンションを含むボイシングではありません。
ドラムはライド風の金属音とノイズ、2・4拍のハイハット風ノイズで拍を支えます。
アコースティック楽器の録音を再現する音源ではありません。

全パートは同じ音声時計で同期し、テンポ変更・区間ループに追従します。
カウントイン中は伴奏を休ませ、N.C.ではベース・ピアノを休ませてドラムは続けます。
